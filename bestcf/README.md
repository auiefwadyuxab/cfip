# BestCF 自动提取与同步

每天北京时间 **22:17** 抓取优选页面，并按 `url` 的四行顺序同步面板。每个面板最多49条。

## GitHub Secrets

在 `Settings → Secrets and variables → Actions` 添加两个 Secret：

- `ADMIN`：四个面板共同的管理员密码。
- `url`：四个后台完整地址，一行一个，必须按你设定的四个面板顺序填写；地址不要写入公开文件。

每行格式为 `https://你的域名/admin`，不要添加名称或其他文字。

## 文件

- `bestcf/bestcf.py`：抓取、分配和同步脚本。
- `bestcf/yuan.txt`：第二个面板原本要保留的链接，一行一个。程序会去重，以此文件为准。
- `bestcf/bestcf.txt`：完整抓取结果，先放 `sub://`，空一行后放普通链接。
- `bestcf/bestcf.log`：只记录本次运行的数量、分配和结果，不重复保存完整链接。

## 分配规则

| `url` 行 | 内容 |
|---:|---|
| 1 | 普通链接前49条 |
| 2 | `yuan.txt` + 超过98条后的普通链接 |
| 3 | 全部 `sub://` 订阅 |
| 4 | 普通链接第50～98条 |

普通链接少于或等于98条时，第二行只保留 `yuan.txt`；超过98条时，多出来的链接追加在其后。若第二行总数超过49条，程序停止，不会截断链接。

## 运行

手动运行 Actions 默认 `dry_run=true`，只读取和预览，成功或失败都不写入面板、`bestcf.txt` 或 `bestcf.log`，工作流也不会提交文件。确认分配正确后，把 `dry_run` 设为 `false` 再运行。

每天北京时间22:17自动正式运行。若链接集合与面板内容均无变化，不重写输出和日志，也不产生 Git 提交。
