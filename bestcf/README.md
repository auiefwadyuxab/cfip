# BestCF 自动提取与面板同步

每天北京时间 **22:17** 抓取优选页面，并按 `url` 变量的四行顺序同步面板。每个面板最多 49 条。

## 只需设置两个 GitHub Secret

位置：`Settings → Secrets and variables → Actions → New repository secret`

- `ADMIN`：四个面板共同使用的管理员密码。
- `url`：四个面板的完整后台地址，一行一个，必须严格按下面顺序填写；四个地址都只放在 Secret，不要写进公开文件。

| `url` 行号 | 用途 |
|---:|---|
| 第 1 行 | 普通链接优先区，最多 49 条 |
| 第 2 行 | `yuan.txt` 原始内容，后面接收超过 98 条的临时溢出 |
| 第 3 行 | 只放 `sub://` 订阅链接 |
| 第 4 行 | 普通链接第二优先区，最多 49 条 |

每行填写完整的 `https://你的域名/admin` 地址，不加名称、逗号或其他文字。

## yuan.txt 怎么用

`bestcf/yuan.txt` 和 `bestcf.py` 放在同一目录。里面一行一个链接，代表第 2 行面板平时应该保留的原始内容。

脚本每次都以 `yuan.txt` 为准：

- 普通链接不超过 98 条：第 2 行只放 `yuan.txt` 的内容。
- 普通链接超过 98 条：多出来的链接接在 `yuan.txt` 后面。
- 数量后来降到 98 条或以下：第 2 行自动恢复为当前 `yuan.txt` 的内容。
- 你修改 `yuan.txt` 后，下次运行就按新内容同步，不需要手动备份或恢复。

`yuan.txt` 里的链接是普通公开链接，不需要放进 Secret。以后要增删原始链接，直接编辑这个文件即可。

## 运行和日志

- 每天北京时间 22:17 自动正式运行。
- 手动运行 Actions 默认 `dry_run=true`，只读取并预览，不写入面板；确认分配正确后再关闭预览。
- `bestcf.txt`：`sub://` 在前，空一行后是普通链接。
- `bestcf.log`：只保留最近一次有变化或失败的运行报告；没有变化时不改日志。
- 不保存面板备份、不写入面板地址、不自动回滚。若中途某个面板写入失败，再运行一次会重新读取四个面板并按最新目标补齐。
